# Frozen evaluation protocol

The computational study was developed and executed on 27 October 2026. The final release packages that evaluated snapshot and the subsequent publication reporting corrections. It is not a preregistered clinical or biological experiment.

Development used a separate mechanism seed. The formal controlled evaluation uses the saved independent mechanism and sampling seeds, reports all specified families and budgets, and retains compensatory failures and zero-endpoint checks. Model accuracy, mechanism recovery and exact attribution of the fitted predictor are separate quantities.

The real-case plan was saved before the formal attribution comparison. Sample identifiers are selected deterministically with richness coverage. Coordinates are ranked from training-only information with fixed controls; the plan is not optimized for PCCV's performance. Complete per-case records and both sampling repetitions are retained. The later illustrative example follows the first frozen sample and first coordinate; its displayed taxa follow the stated union-of-ranks rule.

The resource-internal sample partition and all training seeds are fixed in configuration. Metadata recovery exposed repeated-subject overlap, which is disclosed. The entire-study test set is chosen by verified study size without examining model performance. Ambiguous and unmatched samples are excluded from that stricter design and recorded in the ledger. Study-holdout explanation auditing reuses the six internally selected coordinates.

Attribution comparisons count true predictor query rows, including calibration. Exact small-game references are computed by exhaustive coalition sums. Exhaustive small-game KernelSHAP is an implementation check and is not presented as a sampled competitor with an artificially lower budget. The polynomial benchmark settings and source version are documented in code and results.

The final software adds portable paths, argument guards, isolated execution, integrity manifests, tests and publication plotting. A reporting correction preserves the literal `null` family label before excluding the ten fully null games from the null-player summary. It does not modify raw experimental outcomes, checkpoints or matrix values. The release validation report states precisely which checks were rerun locally.
