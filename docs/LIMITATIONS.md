# Interpretation and validation scope

The game changes one standardized annotation coordinate across selected present carriers, holding the predictor and other inputs fixed. Scores describe that game and predictor. They are not measured pathway activity, flux, growth, ecological keystoneness or an established causal disease mechanism.

Repeated-token inference is exact for identical inputs with shared operations, compatible masks, no active positional signal and no random dropout. The reported CPU benchmark uses the same compatible archived checkpoint under dense and grouped execution. It is not an end-to-end PCCV speed claim or a guarantee for arbitrary Transformers.

PCCV uses an endpoint-calibrated weighted cubic proxy and two-fold cross-fitted residual correction. Its query comparison counts calibration probes. Strong compensation can reduce proxy usefulness. The controlled games contain one half planted null players and are mechanism benchmarks rather than ecological simulators. The recent polynomial comparison evaluates the disclosed complete cubic paired/unpaired settings, not every authors' software option or OddSHAP.

The 108 real cases are selected communities and annotation coordinates. Six exact real references are conditional eight-carrier subgames, not full-game exact enumerations. The entire-study holdout uses one source, one training seed and the six internally selected coordinates. Internal splits include known repeated-subject overlap. Across-model comparisons concern endpoint rankings.

PCCV and permutation estimates have median real-game rank correlation 0.9987. That is concordance, not an independent accuracy proof or statistical equivalence result. Real curve differences have bootstrap intervals containing zero, and repeat sampling has not established a consistent stability advantage. The real example illustrates carrier contribution relative to abundance and is shared by both sampling methods.

Frozen matrices, checkpoints and individual results support computational checking. Original raw-processing and annotation lineage remain incomplete. Software licensing does not resolve upstream data permissions. Hardware-dependent timing and same-seed replay should be distinguished from independent seed or biological replication.
